# Restauración y recuperación — requisitos

**Todavía no implementado**. Esta guía define el resultado esperado y evita confundir una reinstalación de programas con una recuperación de datos.

- Si se formatea solo la microSD: identificar el HDD existente sin escribir, reinstalar módulos seleccionados y recuperar la configuración respaldada.
- Si se pierde el HDD: restaurar desde una copia externa verificada, incluyendo proyectos, datos de aplicaciones y volúmenes/BD consistentes.
- Si se migra desde JaviPi original: importar datos por módulos con vista previa, respaldos y aceptación expresa, sin tocar la instalación anterior.

Las claves y credenciales no se incluyen en Git. La restauración de secretos debe tener su propio mecanismo y permisos. No prometer recuperación sin un ensayo aislado de restauración.
